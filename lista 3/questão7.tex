\section{Questão 7}
Discuta sobre o conjunto de valores possíveis para as constantes $a$ e $b$ de modo que
%
\begin{equation*}
    F_X(x) = 
    \begin{cases}
        0,     & x \leq 0 \\
        a - ae^{-x/b}, & x > 0
    \end{cases}
\end{equation*}
%
seja uma CDF válida.

\respostas

Para a CDF ser válida, é necessário que seja não-negativa, não-decrescente, e satisfaça
$\lim_{x\to-\infty} F_X(x) = 0$, $\lim_{x\to+\infty} F_X(x) = 1$.
O primeiro requisito impõe que tanto $a$ quanto $b$ sejam positivos.
Essas imposições também garante que $F_X$ seja não-decrescente.
Como o limite em $-\infty$ é trivial, resta garantir o limite em $+\infty$.
Para $b>0$, $\lim_{x\to+\infty} F_X(x) = a$.
Conclui-se então que $F_X$ é uma CDF válida se e somente se $a=1$ e $b>0$.
Quanto maior $b$, mais lentamente $F_X(x)$ tende a $1$.
